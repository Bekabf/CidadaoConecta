PRECISA DE AJUDA?

Ficou com alguma dúvida?

Informações simples para ajudar você a entender a plataforma.

O que posso registrar? ⌄

Problemas como buracos, iluminação pública, vazamentos, acessibilidade e limpeza urbana.

Posso adicionar fotos? ⌄

Sim. O formulário aceita até três imagens opcionais. Nesta demonstração, elas não são enviadas ao servidor.

O CidadãoConecta é um serviço da prefeitura? ⌄

Não. Este é um projeto acadêmico independente. Registrar uma ocorrência aqui não equivale a solicitar um serviço oficial da prefeitura.

Posso usar pelo celular? ⌄

Sim. O site foi planejado para funcionar em computadores, tablets e celulares.
